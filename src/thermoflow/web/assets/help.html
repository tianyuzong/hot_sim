快速开始：第一次先跑通这 8 步

请从服务地址进入 点击打开当前服务工作区（当前服务地址的 /docs）。本次 firework 端口转发地址是 http://127.0.0.1:18080/docs；自行安装时默认端口是 8000，以实际启动配置为准。不要双击 HTML 文件，也不要使用 file://；本页面需要同一服务提供项目、求解和结果接口。
  1. 导入几何。点击左侧“导入 STL”，选择文件，保留“先导入，随后设置”即可。
  2. 确认尺度。在“几何”里选择真实的“文件坐标单位”。常见机械 STL 使用 mm，但一定要对照“确认后实际尺寸”；把 mm 误选成 m 会让结果完全失真。
  3. 确认材料。在“材料”中逐组件选择材料目录项，或选择“自定义物性（下方填写）”。核对后勾选“我已逐组件确认当前材料、导热系数、密度和比热容”。
  4. 进入工况。点击“下一步：热源与时长”。第一次建议选择瞬态导热，并从简单工况开始。
  5. 放置热源。点击“打开热源编辑器”，按需建立点、线、面或体热源；若使用“嵌入工件”，稍后务必检查网格中的实际映射。
  6. 填写起步参数。室温输入 293.15 K（20℃）；可先用“工作持续时间” 60 s、“时间步长” 0.3 s。点击“应用到草案”。这些只是便于首次跑通的起步值，不是所有模型的推荐工程参数。
  7. 检查并计算。先查看右侧“参数检查”：红色是必须修改的冲突，黄色是需要核对的风险，点击“定位”可跳到输入项。修改后等待草案保存并重新检查，再勾选“我已检查材料、热源、初始温度、散热条件与网格设置”，点击“确认并开始仿真”。系统会自动生成网格并求解；出现网格复核时先读提示，再决定是否接受。
  8. 查看结果。进入“结果”后，若看到“一次加载 201 个真实温度帧…”，请等待预加载完成。随后播放或拖动时间条，并优先查看“真实温度”。

稳态导热

回答“边界长期保持后，最终温度场怎样”。它没有加热过程和时间帧，适合关心最终平衡状态时使用。

瞬态导热

回答“温度随时间怎样传播”。需要初始温度、持续时间和时间步长，适合观察热源附近先升温、再向远处扩散的过程。

材料：STL 不会告诉你它是什么材质

平台提供铝合金 6061-T6、C110 紫铜、304 不锈钢和 Inconel 718 等目录项，也允许填写自定义导热系数、密度和比热容。目录中的默认候选值不是从 STL 推断出的实物材料，必须逐组件核对。

  • 导热系数影响热量传播速度与温度梯度；密度 × 比热容决定单位体积储热能力。
  • 结果超出材料数据的有效温区，或材料未提供完整有效温区时，页面会警告。当前后端仍以常物性外推，不能据此认为高温物性仍准确。
  • 已完成的研究会锁定输入。要改材料，请点击“修改材料与物性（保留原结果）”创建可编辑副本，重新确认并求解；旧温度场不能当作新材料的结果。

热源：位置是固定方案，不是运动轨迹

“局部功率热源”以 W 输入功率。点击“打开热源编辑器”后，可以用“＋ 新增热源”建立多个独立热源；选中列表中的热源后可修改，使用“删除当前热源”可删除。

检查实际映射，而不只看输入坐标 点和线也会落到有限体积的网格单元，不是数学上的无体积奇点。体素网格可能把输入位置调整到最近的可用单元；网格生成后，请查看实际映射中心、单元数与风险提示。孔洞或空气不能当成实体热源区域。

画布上的拖动只是在修改这一版方案的固定位置，不表示热源会沿拖动路径运动。每次改变位置、形状、功率或材料，都要重新求解。

边界与温度：先做简单、说得清的工况

最容易理解的第一组工况

仅启用局部功率热源，并启用“未定温表面的全局对流”；初始温度与环境温度都填 293.15 K。先不要额外添加固定冷热端。这样表达的是“室温工件在环境中被局部持续加热”。

固定温度不是热源功率

“定温边界”会把所选区域强制保持在指定温度，它代表一个理想恒温约束，不等同于施加多少 W 的加热器。求解器会计算维持该温度所需的净输入或净散热。

热流和换热可以按物理需要组合

“表面热流”以 W/m² 指定表面能量流入；“区域对流”描述该区域与流体的换热。当前引擎允许在区域上组合热流、对流（以及需要时的辐射），不能简单理解为“任何重叠都非法”。区域对流会替换该区域原有的全局对流；重复的同类约束、重复定温或映射后温度冲突则会被检查。

冲突示例：同一区域被设置成 7 K 和 4 K 如果“定温边界”中有两行都指向 X 最小侧（Xmin），一行 7 K、一行 4 K，它们是在同一区域施加两个互相矛盾的温度，而且 7 K 等于 −266.15℃，并不是 7℃。请点对应行右侧的“×”删除不需要的一行；如果确实需要两个温度，应把其中一行明确改到另一个物理区域，并核对三维画布中的区域位置。不要为了让校验通过而随意换区。

温度单位要分清

  • 工况输入使用绝对温度 K：20℃ = 293.15 K，7 K = −266.15℃。
  • 结果“真实温度”显示 ℃。
  • “空间温差”显示相对当前最低温度的 Δ℃；其中 0 表示“与本帧最低点相同”，不是绝对零度。
  • “相对环境温升”和“温差跨度”中的 K 是温差，1 K 的温差等于 1℃ 的温差。

网格与求解：自动完成，但仍要人工复核

点击“确认并开始仿真”后，系统会自动生成真实体素网格、检查热源和边界映射，然后进入求解。目标单元尺寸越小，通常越能分辨局部特征，但活动单元数、内存和求解时间也会增加。

  • “需关注”表示存在非阻断提示。请查看真实网格、体积偏差、各轴活动层、连通性和映射单元数；理解风险后，才勾选“我已查看真实网格和质量提示，并接受本次简化网格的建模风险”。
  • “阻止求解”是硬性问题，不能靠勾选跳过。需要修改区域、网格或工况后重试。
  • 材料温区、开放网格、粗网格、体素近似等提示不一定都是硬错误，但也不能整体忽略。页面中的提示、待确认信息和当前模型范围都需要用户逐条判断。
体积偏差不是统一精度承诺 已验收的两个支架样例体素体积偏差约为 15.88% 和 17.73%，这只是那两个网格的实际数据，不代表所有模型都会落在 16%–18%。请以当前“网格预览”中的实际数值为准，并用网格加密比较判断结果是否稳定。

结果：先看真实温度，再看内部传播

瞬态结果默认从 0 秒开始。若初始温度设置为均匀室温，那么 0 秒的“真实温度”应全工件相同；此时“空间温差”为 0，只表示这一帧各处没有温差。

  1. 等待 201 个真实温度帧预加载完成，再播放或拖动时间条。保存时刻可能不是均匀间隔，请以时间条显示的实际秒数为准。
  2. “真实温度”使用全时段固定色标，拖动时间时颜色可直接比较，不会因为每帧自动缩放而夸大变化。
  3. 用“空间温差”观察同一帧的冷热分布，但用“真实温度”判断工件是否整体升温。
  4. 表面云图不能证明内部温度相同。需要时使用“剖面”，或导出当前帧 / 末态 VTK；精确数值核验以原始单元温度为准。

若热源附近先升温、较远位置随后变化，这是瞬态传热的正常表现。仅凭颜色看起来接近，不能判断已经达到稳态。

常见问题

页面打不开，或项目、结果一直加载不出来

先通过当前服务的工作区链接进入，确认不是 file://。本次 firework 使用本机转发端口 18080；自行安装默认使用 8000，以实际配置为准。再检查 ThermoFlow 服务和 SSH 端口转发是否仍在线。不要在同一数据目录重复启动多个服务实例。

为什么“确认并开始仿真”不可点击？

依次检查：是否确认 STL 尺度、是否逐组件确认材料、参数输入是否有效、是否勾选“我已检查材料、热源、初始温度、散热条件与网格设置”，以及是否还有待处理的建模建议或保存冲突。

为什么同一个定温区域不能填写两次？

同一区域只能有一个确定的固定温度。删除多余行，或把其中一行有意识地改到另一个实际物理区域；若两个不同选区在粗网格上映射到同一批单元且温度不同，也需要调整选面或细化网格。

为什么热源坐标看起来正确，却没有映射成功？

输入点可能在孔洞、空气中或离实体体素太远。检查放置方式、嵌入深度、尺寸，以及网格报告里的实际映射中心和单元数；必要时移动热源或细化网格后重算。

出现材料有效温区警告，还能继续看结果吗？

可以把结果用于定位设置问题或观察趋势，但不能直接作为工程结论。应换用覆盖该温区的可靠材料数据，或补充温度相关物性后重新验证。

这个结果可以直接用于工程定型或认证吗？

不可以。当前后端是体素近似、常物性固体导热模型，尚未替代网格收敛、实测温度对比、温度相关物性、相变或其他所需物理验证。它适合方案检查和迭代，不是工程认证结论。

AI 工况描述、建模对话和 Agent 优化都是可选功能。完成上述手动流程不需要调用外部 AI。
