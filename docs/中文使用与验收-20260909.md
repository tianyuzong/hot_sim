# ThermoFlow 中文使用与实际验收（2026-09-09）

## 页面内的中文入门说明与参数检查

页面顶部固定提供 **“使用说明”** 入口，在新标签页打开中文入门指南，不会离开或修改当前草案。也可以直接访问 [中文入门指南](http://127.0.0.1:18080/assets/help.html)。指南覆盖导入、尺度、材料、点/线/面/体热源、边界、时长、网格、求解和温度结果。

右侧 **“参数检查”** 会持续显示问题：红色冲突必须修改，黄色风险需核对。每项说明具体行号、当前值和建议；支持定位的项目点击 **“定位”** 即可跳到输入框。修改后等待草案保存，提示会自动更新，确认前还会重新检查当前版本。

例如同一个 X 最小面被同时设置成 7 K 和 4 K，会列出两条定温边界的冲突。7 K 是 −266.15 ℃，并不是 7 ℃。请按真实工况删除重复行或修改目标区域；系统只提示，不会擅自改温度、删除边界或替换材料。

## 最短完整操作流程

1. 点击左侧“导入 STL”，选择文件。使用默认“先导入，随后设置”即可，不需要先写 AI 提示词。
2. 在“几何”中确认长度单位。下面两个样例都选 **mm**；必须核对尺寸，不能把 mm 当成 m。
3. 确认尺度后自动进入可编辑的瞬态草案。在“材料”中，为每个组件选择铝合金 6061-T6、C110 紫铜、304 不锈钢或 Inconel 718。也可以选“自定义物性（下方填写）”，输入导热系数、密度、比热容。STL 本身不包含可靠的材料信息，默认候选材料不代表实际材质。
4. 核对材料后勾选“我已逐组件确认…”，点击“下一步：热源与时长”。
5. 点击“打开热源编辑器”或画布“编辑热源”。设置热源类型、功率、位置和嵌入深度；多个热源使用“＋ 新增热源”。选择列表中的某个热源可分别修改或删除。
6. 点击“应用到草案”，核对工况：初始温度、环境温度、对流系数、持续时间、网格尺寸。输入温度仍用 **K**，例如 **20℃ = 293.15 K**，不要把室温输入成 20 K。结果温度显示为 **℃**。
7. 勾选“我已检查材料、热源、初始温度、散热条件与网格设置”，点击“确认并开始仿真”。系统自动生成网格并求解。若网格质量需要人工确认，先阅读风险、确认后继续；质量阻断不能靠确认跳过。
8. 求解完成后打开“结果”。默认显示 **0 秒的真实初始温度**。等待全帧预加载完成，点击播放，或拖动时间条到 10、30、60 秒。色标全时段固定，变化的是工件各位置的温度颜色。时间帧不是均匀间隔，早期采样更密，请以时间条文字为准。

普通手动流程已经不依赖 Codex/AI 生成方案。AI 描述、建模对话和 Agent 优化是可选功能；健康检查中的 AI 配置存在，也不等于每次外部 AI 调用都保证成功。

## 热源、材料与结果的几个关键点

- **点、线、面、体**均有设置入口。点设置位置和半径；线设置起点、终点和半径；面设置法向、宽高和映射厚度；体设置 X/Y/Z 尺寸。点/线也会映射到有限网格体积，不是数学上无体积的奇点。
- “贴附表面”和“嵌入工件”是不同映射方式。嵌入时需检查实际映射位置、深度和单元数；体素网格不保证精确落在输入坐标上。不能把孔洞或空气当作实体热源区域。
- 画布热源拖动用于**修改方案中的位置**；它不等于已经计算了沿拖动轨迹运动的热源。修改后要重新求解。本次验收是固定位置、持续加热，不是移动轨迹热源验收。
- 已完成的研究是锁定的。在“材料”中点击 **“修改材料与物性（保留原结果）”**，即可生成可编辑副本；修改材料后必须重新确认并求解，不能把旧温度场当成新材料结果。
- “真实温度”显示绝对温度℃；“空间温差”是相对当前最低温度的差值，单位标为 Δ℃。温差为 0 不代表绝对零度。右栏“相对环境温升”“温差跨度”的 K 也表示温差。
- 表面云图不代表内部各处温度相同。使用“剖面”检查内部，或导出当前帧/末态 VTK。表面颜色由原始求解场做节点插值，数值核验以原始单元温度为准。
- 本次默认无固定冷热端，全工件从室温开始。热源附近先升温，热量再向远处传递。不能仅凭颜色看起来相近就认定不再扩散，应同时比较不同位置和时刻的数值。
- 如需更长时间，可调整“工作持续时间”和“时间步长”，但仍受网格规模、时间步策略和单任务超时限制。本次真实样例验收到 **60 秒**，没有声称任意时长都已验证。

## 修复内容与验证边界

已修复导入后错误跳回旧工件、材料编辑入口不清晰、普通手动流程等待 AI、确认入口分散、60 秒预算不合理拦截、默认展示空间温差误导、温度单位含糊、右栏任务区挤占结果、等待温度帧时整个项目迟迟不显示等问题。读取温度帧时也不再把末态热流密度冒充当前帧热流。

真实剖面检查还发现快速切换轴和位置会争用读取锁、误报“已有正在执行的操作”。现已让只读查询等待锁，并在前端合并过时的剖面请求：正在读取的一帧完成后，只请求最新位置，避免连续拖动向服务器堆积大量读任务。

播放数据改为共享网格几何，一次加载各帧真实温度，减少重复顶点和重复解析 VTK。温度播放拖动使用本地已加载帧；热流和剖面可能另外读取当前帧。原始求解数据和完整性校验保留，没有用统一升温或伪造扩散动画替代求解。

本次后端全套测试 **177 项通过**；随后新增只读锁并发用例，相关可视化、瞬态与手动流程 **20 项通过**。6 个前端专项脚本通过；隔离浏览器完整操作回归通过（桌面/窄屏布局、固定色标、材料确认、热源操作、网格复核和求解流程，无页面脚本错误）。此外，在真实服务中操作了上述两个用户样例。两类验收不能互相替代。

**重要限制：这是体素近似、常物性固体导热验收，不是工程精度认证。** 两件几何的体素体积偏差分别约 **15.88% 和 17.73%**。能量闭合通过不代表几何离散误差小；未完成网格收敛、实测温度对比、温度相关物性或相变验证。用于实际设计前，需要可靠材料参数、准确边界条件和进一步精度验证。
